# KIN Wellness

Online consultations, diet charts and wellness products for KIN clinic.

- **frontend/** – React 19 + TypeScript + Vite + Tailwind CSS v4
- **backend/** – FastAPI + SQLAlchemy 2 + Alembic, layered `api → services → dao → models`
- **Postgres 17** in Docker

## Run it

```bash
cp .env.example .env          # then set real passwords / JWT_SECRET
```

**Everything in Docker**

```bash
docker compose up --build     # web: http://localhost:5173  api: http://localhost:8000/docs
```

**Or run the apps locally, with only the database in Docker**

```bash
docker compose up -d db                     # Postgres on localhost:5433

cd backend
uv sync
uv run alembic upgrade head                 # create tables
uv run python -m app.seed                   # default schedule, products, diet plans
uv run uvicorn app.main:app --reload        # http://localhost:8000/docs

cd ../frontend
npm install
npm run dev                                 # http://localhost:5173
```

The seed script only fills empty tables, so it is safe to re-run.

## What's where

| Page | URL | Notes |
|---|---|---|
| Home | `/` | |
| Book consultation | `/book` | `?focus=<care-area>` pre-ticks a concern |
| Diet charts | `/diet-plan` | PDF generated by the backend |
| Products | `/products` | |
| Admin | `/admin` | Sign in with `ADMIN_USERNAME` / `ADMIN_PASSWORD` from `.env` |

Admin can manage appointments (status, private notes), the doctor's weekly hours, holidays,
booking settings (clinic time zone, slot length, fee) and products.

### Scheduling rules

- Weekly hours are stored in the **clinic time zone** (default `Asia/Kolkata`, 9:00–21:00 every day).
- Patients pick their own time zone and see slots in local time.
- Slots on holidays, already booked, sooner than the minimum notice, or beyond the booking window are hidden.
- A partial unique index guarantees one active booking per slot; cancelling frees it.

## Checks

```bash
cd backend && uv run pytest && uv run ruff check app tests   # tests use a kinhospital_test database
cd frontend && npm run build && npm run lint
```

## Database changes

Edit models in `backend/app/models/`, register new ones in `models/__init__.py`, then:

```bash
cd backend
uv run alembic revision --autogenerate -m "describe change"
uv run alembic upgrade head
```
